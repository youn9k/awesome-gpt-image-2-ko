## ⚡️ 프로젝트 비전

GPT-Image2가 널리 제공된 뒤 AI 이미지 생성의 질문은 “이미지를 만들 수 있는가?”에서 “안정적이고 제어 가능하며 재사용 가능한 이미지를 만들 수 있는가?”로 바뀌었습니다. 이 프로젝트는 흩어진 커뮤니티 사례를 Agent와 자동화 워크플로에서 재사용하기 쉬운 Prompt-as-Code 자산으로 바꿉니다.

핵심 목표는 단순합니다. 산문형 프롬프트를 구조화된 프로토콜로 압축하는 것입니다. 배치 생성, 템플릿 시스템, 프로덕션 워크플로가 필요할 때 이 구조는 고립된 사례를 쌓아 두는 것보다 훨씬 가치가 있습니다.

- 🧱 원자적 스키마: 피사체, 조명, 소재, 레이아웃, 시각적 세부 사항을 조합 가능한 부분으로 분리
- ⚙️ 워크플로 친화적: Agent, 스크립트, 자동화 시스템을 위해 설계
- 🧬 구조화된 제어: 레이아웃, 카피, 정보 계층의 제어 가능성 향상

## 🤖 Agent 스킬

이 저장소에는 웹사이트와 같은 데이터를 사용해 GPT-Image2 스타일, 템플릿, 분류, 장면 태그를 선택하는 Agent 스킬이 포함되어 있습니다.

패키지 링크: [npm](https://www.npmjs.com/package/gpt-image-2-style-library) / [GitHub Packages](https://github.com/freestylefly/awesome-gpt-image-2/pkgs/npm/gpt-image-2-style-library)

<p align="center">
  <img src="agents/skills/gpt-image-2-style-library/assets/city-life-system-map.png" alt="GPT-Image2 스타일 라이브러리 스킬로 생성한 도시 생명 시스템 지도" width="760">
</p>

<p align="center"><sub>스타일 라이브러리 스킬로 도시 생명 시스템 지도를 요청해 만든 예시 결과입니다.</sub></p>

### Agent 스킬 빠른 설치

[`skills`](https://www.npmjs.com/package/skills)가 지원하는 Claude Code, Codex, Cursor 등의 도구에 권장합니다.

```bash
npx skills add freestylefly/awesome-gpt-image-2 --skill gpt-image-2-style-library --agent claude-code codex --global --yes --copy
```

지원하는 모든 로컬 Agent에 설치:

```bash
npx skills add freestylefly/awesome-gpt-image-2 --global --all --copy
```

### Claude Code 플러그인 마켓플레이스

Claude Code 안에서 다음 명령을 실행하세요.

```text
/plugin marketplace add freestylefly/awesome-gpt-image-2
/plugin install gpt-image-2-style-library@awesome-gpt-image-2
```

### npm CLI

npm을 선호한다면 CLI를 설치한 뒤 스킬을 로컬 Agent 폴더와 동기화하세요.

```bash
npm install -g gpt-image-2-style-library
gpt-image-2-style-library install all
```

전역 설치 없이도 실행할 수 있습니다.

```bash
npx gpt-image-2-style-library install all
```

GitHub Packages에서 설치:

```bash
npm login --scope=@freestylefly --registry=https://npm.pkg.github.com
npm install -g @freestylefly/gpt-image-2-style-library --registry=https://npm.pkg.github.com
gpt-image-2-style-library install all
```

`install all`은 `~/.codex/skills`, `~/.claude/skills`, `~/.agents/skills`를 포함해 Codex와 Claude Code가 쓰는 일반적인 로컬 폴더에 스킬을 작성합니다. 설치 후 Agent 세션을 다시 시작하세요.

다음과 같이 요청해 사용할 수 있습니다.

```text
gpt-image-2-style-library를 사용해 Codex에 관한 인포그래픽 프롬프트를 만들어 줘.
```

로컬 소스 개발용:

```bash
npm run generate:style-skill
npm run install:skill
```

스킬 원본은 [`agents/skills/gpt-image-2-style-library`](agents/skills/gpt-image-2-style-library/SKILL.md)에 있습니다. 생성된 참조 문서는 [`data/style-library.json`](data/style-library.json)에서 나오므로 웹사이트와 Agent 워크플로가 하나의 스타일 라이브러리를 공유합니다.

## 🔐 웹사이트 인증 및 생성

비주얼 사이트는 개인 브라우저 전용 API 키를 이용한 APIMart 직접 생성을 지원합니다. 개인 키가 없으면 로그인한 사용자는 Supabase Auth, 플랫폼 크레딧, 서버 측 APIMart 키를 통해 계속 진행합니다.

필수 Vercel 환경 변수:

```bash
VITE_SUPABASE_URL=
VITE_SUPABASE_ANON_KEY=
SUPABASE_SERVICE_ROLE_KEY=
SUPER_ADMIN_EMAILS=2689458656@qq.com,canghe0818@gmail.com
APIMART_API_KEY=
APP_URL=https://gpt-image2.canghe.ai
STRIPE_SECRET_KEY=
STRIPE_WEBHOOK_SECRET=
VITE_GA_MEASUREMENT_ID=
GA4_PROPERTY_ID=
GOOGLE_ANALYTICS_CLIENT_ID=
GOOGLE_ANALYTICS_CLIENT_SECRET=
GOOGLE_ANALYTICS_REFRESH_TOKEN=
```

설정 확인 목록:

- Supabase 프로젝트에 [`supabase/migrations/202605090001_user_credits.sql`](supabase/migrations/202605090001_user_credits.sql)을 적용합니다.
- 멤버십 플랜, 크레딧 팩, Stripe 주문 기록, 크레딧 조정 RPC를 추가하려면 [`supabase/migrations/20260509090000_membership_billing.sql`](supabase/migrations/20260509090000_membership_billing.sql)을 적용합니다.
- 알리페이 웹 결제를 켜기 전에 [`supabase/migrations/20260721090000_alipay_webpay.sql`](supabase/migrations/20260721090000_alipay_webpay.sql)을 적용하고 각 크레딧 팩의 검토된 CNY 가격을 설정합니다. [알리페이 웹 결제 설정](docs/alipay-web-payment.md)을 참고하세요.
- 유료 커뮤니티를 켜기 전에 [`supabase/migrations/20260722090000_paid_community.sql`](supabase/migrations/20260722090000_paid_community.sql)을 적용합니다. 보호된 QR, 알리페이 온보딩, 프로덕션 결제·환불 검수가 끝날 때까지 `COMMUNITY_PAYMENT_ENABLED=false`를 유지하세요. [유료 커뮤니티 운영 안내](docs/paid-community.md)를 참고하세요.
- 최고 관리자의 계정 사용량 요약과 강제 크레딧 차감을 추가하려면 [`supabase/migrations/20260512090000_google_account_center.sql`](supabase/migrations/20260512090000_google_account_center.sql)을 적용합니다.
- `$5 / 300 credits` 카탈로그를 업데이트하고 관리자 대시보드 지표를 추가하려면 [`supabase/migrations/20260512143000_pricing_admin_metrics.sql`](supabase/migrations/20260512143000_pricing_admin_metrics.sql)을 적용합니다.
- 사용자별 사례 즐겨찾기를 추가하려면 [`supabase/migrations/20260515090000_case_favorites.sql`](supabase/migrations/20260515090000_case_favorites.sql)을 적용합니다.
- APIMart 작업 ID, 실제 USD 비용, 만료되는 결과 URL, 공급자 인덱스를 추가하려면 [`supabase/migrations/20260828090000_apimart_generation_tasks.sql`](supabase/migrations/20260828090000_apimart_generation_tasks.sql)을 적용합니다.
- `https://gpt-image2.canghe.ai` 및 `http://127.0.0.1:5173` 같은 로컬 개발 URL을 Supabase Auth 리디렉션 URL에 추가합니다.
- Supabase Dashboard에 Google OAuth 자격 증명을 추가한 뒤 Google Provider를 활성화합니다.
- Google 전용 로그인을 강제하려면 Supabase Auth 설정에서 Email Provider를 끕니다.
- `SUPABASE_SERVICE_ROLE_KEY`는 Vercel 환경 변수 같은 서버 측 환경에만 둡니다.
- Stripe Checkout에 웹훅 URL `https://gpt-image2.canghe.ai/api/billing/webhook`을 구성합니다.
- Stripe 웹훅에서 `checkout.session.completed`, `invoice.payment_succeeded`, `customer.subscription.updated`, `customer.subscription.deleted`를 구독합니다.
- `STRIPE_SECRET_KEY`와 `STRIPE_WEBHOOK_SECRET`은 서버 측 Vercel 환경 변수에만 둡니다.
- `gpt-image2.canghe.ai`용 GA4 속성을 만들고, 측정 ID는 `VITE_GA_MEASUREMENT_ID`, 숫자 속성 ID는 `GA4_PROPERTY_ID`에 넣습니다.
- `http://localhost:8080/oauth2callback`을 승인된 리디렉션 URI로 하는 Google OAuth Web Client를 만들고, `GOOGLE_ANALYTICS_CLIENT_ID`와 `GOOGLE_ANALYTICS_CLIENT_SECRET`을 로컬 `.env.local`에 추가합니다.
- `npm run ga4:oauth`를 실행하고 생성된 URL을 열어 `analytics.readonly` 권한을 승인합니다. 콜백 URL을 터미널에 붙여 넣은 뒤 받은 `GOOGLE_ANALYTICS_REFRESH_TOKEN`을 Vercel Sensitive 환경 변수에 추가합니다.

## 🧩 템플릿 입구

전체 템플릿 라이브러리는 [`docs/templates.md`](docs/templates.md)에 있습니다. 위 **프롬프트 템플릿 분류**에서 빠르게 이동하거나, 전체 템플릿 본문은 [산업용 프롬프트 템플릿과 실수 방지 가이드](docs/templates.md)에서 확인하세요.

## 🚀 이 저장소 사용 방법

1. 주요 사례에서 시작해 따라 만들고 싶은 출력 유형을 정합니다.
2. 전체 갤러리를 열어 비슷한 사례를 찾습니다. 먼저 구조를 복사하고 다음에 스타일 단어를 적용합니다.
3. 템플릿 페이지로 돌아가 기본 또는 JSON 템플릿에 업무 변수를 채웁니다.
