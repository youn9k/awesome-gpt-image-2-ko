## 감사와 출처 고지

이 프로젝트는 정리와 연구 과정에서 [YouMind](https://youmind.com/) 및 [OpenNana](https://opennana.com/)의 공개 프롬프트 라이브러리를 참고·사용했으며, 학습·정리·방법론 연구 목적으로만 사용합니다. 관련 콘텐츠의 저작권은 원저자 또는 원 플랫폼에 있습니다. 침해 또는 부적절한 사용이 있다면 연락해 주세요. 신속히 수정하거나 내리겠습니다.

<a name="section-disclaimer"></a>

## 고지

이 프로젝트는 공개적으로 접근할 수 있는 커뮤니티 프롬프트와 예시 이미지만 정리합니다. 기본 목적은 학습과 연구이며 제3자 창작물의 소유권을 주장하지 않습니다.

프로젝트의 모든 프롬프트 사례와 생성 이미지는 공개 커뮤니티, 특히 [YouMind](https://youmind.com/)와 [OpenNana](https://opennana.com/)에서 영감과 데이터를 얻었습니다. 보기 좋은 결과물을 재사용 가능한 코드의 원리로 분해해 학습·정리 및 대형 모델 Agent 연동 자동화 테스트에 쓰기 위해 만들었습니다.

- 원저자 홈페이지, 원문 게시물, 원 저장소 링크 등 원 출처를 최대한 보존합니다.
- 제3자 콘텐츠는 원 출처 저장소의 고지(`CC BY 4.0` 등)와 해당 플랫폼 규칙을 따릅니다.
- 원저자 또는 권리자이며 어떤 콘텐츠의 공개가 부적절하다고 생각하면, 이 저장소에 항목 링크와 함께 Issue를 열어 주세요. 확인 후 빠르게 내리겠습니다.
- 이 저장소는 제3자 콘텐츠의 상업적 사용 가능성을 보장하지 않습니다. 상업적으로 사용하기 전에는 원 권리자에게 직접 허가를 받으세요.
